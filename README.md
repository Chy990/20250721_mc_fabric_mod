# chy

伪键盘操作实现挂机和其他功能。

**当前版本：v3.2.0 · Minecraft Java 1.21.11 · Fabric · Java 21**

## 使用方法

### 安装

1. 安装 Minecraft **1.21.11** 对应的 [Fabric Loader](https://fabricmc.net/use/installer/)（0.19.5 或更高兼容版本）和 [Fabric API](https://modrinth.com/mod/fabric-api/versions?g=1.21.11)。
2. 将 **`chy-3.2.0+mc1.21.11.jar`** 放进该启动配置游戏目录的 `mods` 文件夹。**不要安装 `-sources.jar`，升级时先移走旧 `autoclick` 或旧 `chy` JAR。**
3. 使用 Fabric 配置启动游戏，进入世界后输入 `/chy_help` 查看帮助。

本模组只需安装在客户端。构建产物位于 `autoclick-template-1.21.11/build/libs/`；自行编译请看 [开发与维护文档](DEVELOPMENT.md)。

### 游戏内命令

| 命令 | 用途 |
| --- | --- |
| `/left_click` | 开启/关闭自动左键，默认间隔 12 tick |
| `/left_click <tick>` | 开启或调整自动左键间隔，例如 `/left_click 20` |
| `/right_click` | 开启/关闭自动右键，默认间隔 12 tick |
| `/right_click <tick>` | 开启或调整自动右键间隔，例如 `/right_click 4` |
| `/shift` | 开启/关闭持续潜行 |
| `/chy_help` | 查看全部帮助 |

- **自动左键**：攻击准星指向的实体；无实体时挥手，不自动挖方块。
- **自动右键**：手持方块时尝试放置，也可触发容器、按钮等原版右键交互。配合 `/shift` 可在箱子等方块上放置方块。
- **间隔设置**：参数为正整数 tick，最小 1。左右键独立计时；调整后重新计时，每次无参数重新开启都恢复为 12 tick。
- **状态提示**：聊天栏以红色显示，例如 `自动左键，间隔12 tick`。再次输入相应无参数命令即可关闭。

打开聊天、背包或菜单不会关闭功能；单人世界暂停时自动点击也暂停，恢复游戏后继续。退出世界后所有功能关闭。死亡或旁观期间不自动点击。

右键执行的是周期单击，能否放置取决于准星、距离、剩余方块及服务器规则；正在持续使用物品时不会重复启动右键操作。

## 历史更新

### v1.0.0

- 新增 `/autoclick` 自动攻击功能。

### v1.0.1

- 自动攻击命令改为 `/chy_autoattack`。

### v1.1.0

- 支持 `/chy_autoattack <秒数>` 自定义攻击间隔。
- 默认间隔从 1 秒调整为 0.6 秒，适配 Java 版剑的攻击恢复速度。

### v2.0.0

- 新增 DeepSeek 聊天功能，通过 `/chy_deepseek` 开启或关闭与 DeepSeek-V3 的对话。

### v2.1.0

- 新增 `/chy_help`，在游戏内查看模组使用说明。

### v2.2.0

- 新增 `/chy_say <message>`，在开启 DeepSeek 功能后发送消息。

### v3.0.1

- 移除打开聊天、背包和 Esc 菜单时主动暂停自动攻击的限制，恢复后台挂机用法。

### v3.1.0

- 移除 DeepSeek 聊天功能及相关命令。
- 自动攻击命令改为 `/auto_attack`，默认间隔为 12 tick。
- 修复自定义间隔在关闭后仍被沿用的问题，每次无参数重新开启恢复默认间隔。
- 开启或调整时，在聊天栏和客户端日志显示攻击间隔，包含 tick 和秒数。

### v3.2.0

- 模组由 `autoclick` 更名为 **chy**，介绍改为“伪键盘操作实现挂机和其他功能”，新增 [GitHub 项目链接](https://github.com/Chy990/20250721_mc_fabric_mod)。
- `/auto_attack` 改为 `/left_click`，保留原有攻击行为。
- 新增 `/right_click` 自动右键，支持周期放置方块；左右键默认均为 12 tick，参数统一使用整数 tick。
- 提示改为 `自动左/右键，间隔xx tick`，不再显示秒数。
- 新增 `/shift` 持续潜行开关，更新 `/chy_help` 覆盖全部功能。
- 聊天栏提示和帮助改为红色，加入自定义模组图标。
